## Инструкция по запуску автотестов

**P.S. Предполагается, что на хосте установлен Docker. Если нет - гайды есть в интернете, здесь инструкция по запуску автотестов с отчетами**

___
1. склонировать репозиторий: `https://github.com/elina-kallin/effective_mobile_testing_ui.git`

2. открыть проект в любом редакторе кода

3. открыть терминал и запустить команду `docker build -t em-test .`

4. подождать, пока образ соберётся

5. после успешной сборки образа запустить команду `docker run -p 28081:28081 --rm -v ./allure-results:/app/allure-results em-test`

6. на хосте в папке проекта создастся папка *allure-results*

7. если захочется открыть Allure отчет, открыть в браузере `http://localhost:28081`

8. после всех экзекуций в консоли жмем `Ctrl + C`
___
